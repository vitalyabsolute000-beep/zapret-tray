# Zapret Tray

Небольшая программа для Windows с управлением стратегиями
`zapret-discord-youtube` из системного трея.

## Управление

- ЛКМ по значку: включить или выключить активную стратегию.
- ПКМ по значку: открыть панель управления, выбрать стратегию или перейти в настройки.
- Панель управления показывает состояние zapret, активную стратегию и действие для переключения.
- Статус включения обновляется автоматически, а стратегия определяется по процессу `winws.exe` именно из выбранной папки.
- При смене стратегии работающий `winws.exe` останавливается и запускается выбранная стратегия.
- В «Настройках» можно указать папку zapret, включить автозапуск Windows и выключение zapret при выходе из приложения.
- Выбранная стратегия и настройки сохраняются на компьютере.
- Панель управления открывается из контекстного меню значка в трее.
- Карточка Happ пока демонстрационная: интеграция с клиентом ещё не реализована.

## Запуск

Скачайте последнюю версию установщика со страницы [Releases](https://github.com/vitalyabsolute000-beep/zapret-tray/releases), запустите его и следуйте подсказкам. Установщик ставит только Zapret Tray — сам zapret скачивается отдельно.

После установки запустите приложение, нажмите ПКМ по значку в трее → «Настройки...» и выберите папку `zapret-discord-youtube`. При включении zapret Windows запросит права администратора: они нужны для WinDivert. Установщик создаёт ярлык в меню «Пуск» и предлагает создать ярлык на рабочем столе.

Windows может показывать запрос UAC при каждом запуске приложения, в том числе при включенном автозапуске.

Направление дизайна вдохновлено skill [unslop](https://github.com/heydamir/unslop) Дамира Соколовского (CC BY 4.0).

Приложение запускает стратегии из отдельной копии [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и не включает её файлы в свою сборку. Скачайте проект отдельно, затем укажите его папку в настройках приложения.

## Сборка из исходников

Нужны Windows и .NET 10 SDK. Из корня репозитория выполните:

```powershell
dotnet publish ZapretTrayApp/ZapretTrayApp.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist
```

Для сборки установщика нужен Inno Setup 6. После публикации приложения выполните:

```powershell
ISCC.exe installer/ZapretTray.iss
```
